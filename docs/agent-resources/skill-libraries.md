# Skill Libraries

Skill files are `.md` documents optimized for AI consumption. They act as "recipes" for agents, providing them with the exact context and code patterns required to integrate with WhiteBoxXAI.

## 1. Python Environment Setup
**Filename:** `python_environment.md`
**Purpose:** Instructs agents on how to correctly initialize the Python 3.11 environment and avoid bare `python` execution errors when running tests or servers.

*Download: [python_environment.md](../assets/downloads/python_environment.md)*

## 2. Docker Compose Infrastructure
**Filename:** `docker_compose.md`
**Purpose:** Provides the agent with the internal Docker composition commands to run Postgres, Redis, and the backend locally.

*Download: [docker_compose.md](../assets/downloads/docker_compose.md)*

## 3. Node/Frontend Setup
**Filename:** `node_environment.md`
**Purpose:** Details how to correctly run the Next.js 15 frontend, use TanStack Query, and enforce API client paths.

*Download: [node_environment.md](../assets/downloads/node_environment.md)*
