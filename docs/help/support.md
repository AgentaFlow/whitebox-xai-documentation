# Getting support

## In the dashboard

Choose **Support** in the sidebar footer, or search for **Help & Support** with **⌘K**. The
**Help & Support** page links to these docs and has a request form:

| Field | Options |
| --- | --- |
| **Category** | Technical Support, New Feature Request, General Feedback, Billing |
| **Urgency / Priority** | Low, Medium, High, Critical |
| **Subject** and **Description / Feedback** | What happened, what you expected, and the steps to reproduce it |

The form attaches a little context automatically, so you don't have to look it up: your
organization, the page you were on, your screen size, and whether you use the Enhanced or Classic
layout. You can view exactly what will be
attached before you send it. **Submit Request** returns a ticket reference; quote it in any follow-up.

## Ask a browser AI assistant

Browser sidecar assistants, such as **Copilot in Microsoft Edge** or **Gemini in Chrome**, can read,
summarise and answer questions about the live documentation at
[docs.whiteboxxai.com](https://docs.whiteboxxai.com) while you work. Open the assistant beside a docs
page and ask, for example, *"How do I share a report with an external auditor?"* They read the
current pages; they aren't specially trained on WhiteBoxXAI, so check their answers against the page
they cite. For AI coding agents, see [Agent & Developer Resources](../agent-resources/index.md).

## By email

Email **[support@whiteboxxai.com](mailto:support@whiteboxxai.com)**. Include:

- your organization name and the email address you sign in with
- the AI system (model) name or id, if the issue is about one
- the request id or error message you saw, and roughly when
- for SDK or API issues: the SDK version (`pip show whitebox-xai-sdk`), Python version, and the
  smallest code that reproduces the problem

Never send API keys, passwords, authenticator codes or backup codes. We'll never ask for them.

## Support by plan

| Plan | Support |
| --- | --- |
| **Free** | Community and documentation |
| **Business Cloud** | Standard support, with a response within one business day |
| **Enterprise Edition** | 24/7 support and a custom SLA, plus professional installation and training |

## Security issues

If you believe you've found a security vulnerability in WhiteBoxXAI, email
**[support@whiteboxxai.com](mailto:support@whiteboxxai.com)** with "Security" in the subject line, and
don't include sensitive details in public places such as GitHub issues.
